# Project NOMAD

**An offline internet: Kiwix library, local AI chat and an admin console that keep working with no connection.**

Project NOMAD is an offline internet that runs on one small machine. It bundles a Kiwix library of Wikipedia, medical and survival references, a local AI chat model and an admin console, all served over the local network so everything still works when the connection does not. It was built for the case where the network is the thing that fails.

## Highlights
- Works with no internet: the library, the AI chat and the admin console are all served locally.
- Kiwix library of Wikipedia, medical and reference material, searched from the same page.
- A local AI chat that keeps answering when the cloud is unreachable.
- One machine, one launch: the whole stack comes up together.
