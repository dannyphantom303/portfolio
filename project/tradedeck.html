THE PROJECT

What it is and why it exists

TradeDesk is a multi-agent sports and market desk: a team of specialist agents — scout, news, quant, risk, execution and journal — share one server-side model router instead of each hard-coding a model. The router picks the best installed model per task and records which model handled it and why, so the desk can be read as an audit trail rather than a black box. The panel surfaces live charts, a screener, signals, macro context, portfolio, risk, backtest, alerts, a journal, jobs and approvals.

HOW IT WORKS

The mechanism end to end

No hand-waving: this is the actual chain, in the order it runs.

01

Specialist agents

Scout, news, quant, risk, execution and journal each own one job; none of them decides which model answers.

02

Shared model router

One server-side router selects the best installed model per task and logs the choice plus the reason.

03

Desk panels

Charts, screener, signals, macro, portfolio, risk and backtest read from the same state so they cannot disagree.

04

Journal and approvals

Every decision lands in the journal, and outbound actions wait on an approval rather than firing themselves.

BUILD IT YOURSELF

The steps in order, with the traps

This is the short version of what I would do again — including the parts that bit me first.

01

Put the router between agents and models

No agent hard-codes a model; one shared router makes the choice and records it.

02

Make the router log why

Recording the reason per task is what turns model spend into an auditable list.

03

Read every panel from one state

Charts, screener, risk and journal must share state or the desk shows contradictory numbers.

04

Gate the outbound actions

Execution and alerts wait on approval, so a signal never fires by itself.

WHAT I LEARNED

Notes from the build

NOTE 01A shared router is what makes a multi-agent desk auditable — per-agent model choices are untraceable.
NOTE 02Routing is a cost decision, so the router belongs in front of every agent, not inside one.
NOTE 03One shared state is what keeps the panels from disagreeing.
